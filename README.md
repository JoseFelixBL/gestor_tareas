# Gestor de Tareas

Gestor de tareas simple en línea de comandos, escrito en Python.

## Requisitos

- Python 3.11+

## Instalación

```bash
git clone https://github.com/JoseFelixBL/gestor_tareas.git
cd gestor-tareas
python -m venv .venv
source .venv/bin/activate  # En Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

## Uso

```
pytest
ruff check .
```
